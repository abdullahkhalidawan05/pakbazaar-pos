Return / Exchange

Original receipt required · Admin only

1. Find the original receipt

Find an original receipt to begin.

2. Select items to return

Enter base units, not cartons. Select zero to leave an item unchanged. Damaged items will not be restocked.

3. Choose refund or exchange

4. Review the settlement

Returned items use their original value and allocated tax. Credit returns reduce outstanding account debt first. Replacement items use current prices and tax.

Stock management

Restocking, corrections, and movement history · Admin only

Record a stock change

Select a product to see its current stock.

Use a positive quantity to add stock and a negative adjustment to remove stock. One carton with 12 packs adds 12 base units. For a stock count of 95 when the system shows 100, enter an adjustment of -5.

Recent movements

Latest 100 movements for the selected product, or all products when none is selected. Times use Asia/Karachi. Stock after is the value at the time of each movement.
